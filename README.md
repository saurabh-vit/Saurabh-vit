## 🏗️ Featured AI Projects

### 🔍 [RAG-Based Question Answering System](https://github.com/saurabh-vit/RAG-Based-Question-Answering-System)
> Production-level Retrieval-Augmented Generation pipeline — the full Upload → Chunk → Embed → Retrieve → Generate loop.

- **Document ingestion** via async FastAPI `BackgroundTasks` — PDF & TXT support with token-based chunking (400 tokens, 80-token overlap)
- **Local semantic embeddings** using SentenceTransformers + **FAISS** vector similarity search
- **Grounded answer generation** with Google Gemini API — source attribution + similarity scores per response
- **Latency tracking**, Pydantic validation, rate limiting, and Docker support — not a notebook, a deployable system
- **Tech:** `Python` `FastAPI` `FAISS` `SentenceTransformers` `Google Gemini` `Pydantic` `Docker`

---

### 🧠 [AI Resume Tailor](https://github.com/saurabh-vit/Tailoring_Resume)
> Local-first AI platform that reads a job description and surgically rewrites your resume to match it — with ATS scoring and a Chrome extension for autofill.

- **JD keyword extraction** + bullet-level AI tailoring suggestions via Gemini 2.0 Flash, with accept/apply flow
- **ATS score calculation** against job descriptions — quantified gap analysis, not vague suggestions
- **Cover letter generation**, saved resume versions, and PDF/DOCX export
- **Chrome extension** with profile sync for one-click job form autofill — full-stack AI product, not a script
- **Tech:** `FastAPI` `Google Gemini API` `SQLAlchemy` `SQLite` `Prisma` `JavaScript` `Chrome Extension API`

---

### 🧟 [Zombie Survival AI — Unity + MediaPipe](https://github.com/saurabh-vit/Zombie-Survival-AI-Unity)
> Multimodal AI game: real-time **computer vision** gesture recognition driving **FSM-based game AI** via UDP — two AI systems talking to each other.

- **MediaPipe hand tracking** in Python classifies fist/open gestures in real time from webcam
- Gesture events sent over **UDP** to Unity — Fist → Pick up, Open → Throw — no controller required
- **FSM + NavMesh** zombie AI with 3 states: FollowPlayer → InvestigateSound → Attack
- Sound events from thrown objects propagate through a **radius-based detection system** — stealth/distraction mechanics
- **Tech:** `Unity` `C#` `Python` `MediaPipe` `OpenCV` `NavMesh` `FSM` `UDP`

---

### 💰 [Finance Tracking Backend](https://github.com/saurabh-vit/finance-tracking-backend) · [Live API](https://finance-tracking-backend-epox.onrender.com/docs)
> Production-deployed REST API demonstrating the backend engineering skills that power real ML systems — auth, RBAC, analytics, testing, and deployment.

- **JWT authentication** + **RBAC** (Viewer / Analyst / Admin) with bcrypt, rate limiting on login (5/min brute-force protection)
- **Real-time financial analytics**: income/expense overview, category breakdowns, monthly trends — optimised SQL aggregation with composite indexes
- **Unit test suite** (pytest) — 5/5 passing; covers auth service, token decode, and summary calculations
- Live on Render with Swagger UI docs — demonstrates the same FastAPI patterns used across all AI projects
- **Tech:** `FastAPI` `SQLAlchemy` `JWT` `bcrypt` `Pydantic` `pytest` `Render` `Python`
